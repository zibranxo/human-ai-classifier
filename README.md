#AI vs Human Text Classification

A machine learning and deep learning pipeline to classify AI-generated vs human-written text using classical models, neural networks, and transformer-based architectures.

#Overview

This project focuses on detecting whether a given text is written by a human or generated by AI. It combines statistical and stylometric feature engineering with multiple models to achieve robust performance.

#Pipeline

Text Data → Preprocessing → Feature Extraction → Feature Selection → Model Training → Evaluation

Key Components

Preprocessing: text cleaning, tokenization, normalization

Feature Extraction:

TF-IDF vectors
Stylometric features (lexical, syntactic, writing style patterns)

Feature Selection: reduces dimensionality and improves efficiency

Models:

SVM
Decision Tree
ANN
BERT

Hybrid Model: ANN combining TF-IDF and stylometric features

Features
Multi-model implementation (ML + DL + Transformer)
TF-IDF + stylometric feature engineering
Feature selection for optimization
Hybrid ANN architecture
Progressive learning rate scheduling
End-to-end pipeline
Evaluation Metrics
Accuracy
Precision
Recall
F1-score
